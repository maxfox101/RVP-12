# RVP-12 — оптимизация и SEO (БазМет)

## Что это
Оптимизация React-сайта БазМет: WebP, lazy-load, meta description, robots.txt, sitemap. В `lighthouse/` сохранены замеры Lighthouse до и после.

Отчёт `РВБ-12.docx` в репозиторий не входит.

## Как запустить
Нужны API (работа 8) и при необходимости CMS (работа 9). Минимально:
```bash
npm install
npm run dev
```
Сайт: http://127.0.0.1:5173/

Проверка: Chrome → DevTools → Lighthouse → Desktop.
